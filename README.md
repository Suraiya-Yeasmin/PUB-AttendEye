# PUB-AttendEye
PUB AttendEye: Computer-Vision-Based Smart Attendance System
## 🎯 Project Overview

PUB AttendEye is a computer-vision-based smart attendance management system developed for the PUB CSE Fest 2026 Hackathon.

The system uses face detection and recognition to support digital attendance recording and help make classroom attendance management more organized and efficient.

## 🚀 Key Features

* Teacher Login and Dashboard
* Student Management
* Face Enrollment and Recognition
* Digital Attendance Recording
* Duplicate Attendance Prevention
* Teacher Review Queue
* Attendance Reports and CSV Export

## 🛠️ Technology Stack

* Python
* FastAPI
* OpenCV
* YuNet Face Detection
* SFace Face Recognition
* SQLite
* HTML, CSS, and JavaScript

# PUB AttendEye API

Generated by `python scripts/gen_api_docs.py`. All state-changing calls need the header `X-Requested-With: AttendEye` and a session cookie from `POST /api/auth/login`. Errors are JSON `{"detail": ...}`; validation errors (422) use `{"detail": {"message", "fields"}}`. Face templates are never returned by any endpoint.
